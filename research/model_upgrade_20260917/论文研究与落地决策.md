> 历史研究记录。文中“交接包”指当时本地交接版本；GitHub 发布内容及复算所需私有输入见 [训练说明](../../docs/TRAINING.md)。

本轮把检索结果转成了可运行、可比较的模型实验：保留现有 WARP 时序速度模型，新增针对 G1 香蕉搬运的双视角阶段网络。论文优点是否适合本项目，由相同数据划分上的对照实验决定。以下为截至 2026-09-17 核对的原始论文、作者页面或正式会议页面。

| 工作与来源 | 可借鉴的核心思想 | 本项目的处理 |
|---|---|---|
| [WARP-RM，2026 预印本](https://arxiv.org/abs/2606.28320) | 时间扭曲构造进展速度监督 | 延续已完成的 DINOv2 方法适配及速度曲线，保持其单位与评分来源 |
| [SARM，ICLR 2026](https://qianzhong-chen.github.io/sarm.github.io/)；[正式论文](https://openreview.net/pdf/a003594857c5bc6d40ac553e082c79c1dcd1f921.pdf) | 阶段分类与阶段内进度联合建模，阶段先验减少不同速度演示之间的标签冲突 | 本轮主要落地方向：阶段头、阶段条件进度头、训练集阶段时长先验；明确属于任务适配，不是原论文完整复现 |
| [ReWiND，CoRL 2025 Oral](https://rewind-reward.github.io/) | 成功视频倒放构造回退；任务描述错配提供负监督；避免绝对时间位置捷径 | 实现并训练“倒放＋前进后回放”时序候选。当前只有一个任务，未实现多任务语言错配训练 |
| [PROGRESSOR，ICCV 2025](https://ripl.github.io/progressor/) | 建模进度分布；通过在线交互修正分布外状态的奖励 | 借鉴“不确定时交给复核”的原则，采用三模型分歧和验证集温度校准；没有复现其高斯目标或在线 push-back |
| [SCIZOR，ICRA 2026 Oral](https://ut-austin-rpl.github.io/SCIZOR/) | 分别处理不推进的状态动作片段和重复片段 | 保留片段级分析接口；暂不自动删除低进度片段，恢复动作可能有价值。去重需要状态动作联合表示，不能只看相似画面 |
| [DemInf，RSS 2025](https://www.roboticsproceedings.org/rss21/p023.html) | 用状态动作互信息同时衡量动作多样性与可预测性 | 作为下一轮“数据价值”评分候选；18 段同场景数据不足以稳定验证此类分布估计，不把阶段识别冒充互信息质量分 |
| [CUPID，CoRL 2025 官方实现](https://github.com/agiachris/cupid)；[论文](https://arxiv.org/abs/2506.19121) | 用影响函数联系训练数据和策略表现，并重新训练策略验证选择效果 | 确立最终验收方向：数据打分必须接受下游策略检验。目前尚无本任务策略闭环对照，不能宣称机器人成功率提升 |
| [DataMIL，2025 预印本/作者页面](https://robin-lab.cs.utexas.edu/datamodels4imitation/) | 以目标任务验证损失作数据选择代理，按时间片段降低估计噪声 | 保留完整录像划分和可复算实验记录；计划在有策略训练基线后比较“阶段分数筛选”和“策略损失驱动筛选” |
| [Rank2Reward，ICRA 2024](https://rank2reward.github.io/) | 从视频时序排序学习奖励，结合分布外负例处理 | 提醒我们单调的时间标签不足以覆盖真实失败；本轮将错误放置后的恢复录像单列为压力样例 |
| [GVL，ICLR 2025](https://generative-value-learning.github.io/) | 利用视觉语言模型做任务条件进度判断；打乱帧顺序检查时间捷径 | 借鉴任务条件和视觉证据核查思路；当前实验没有调用外部视觉语言模型，研究标注来源单独披露 |
| [RoboReward，2026 预印本](https://arxiv.org/abs/2601.00675) | 借助任务重标注与视频截断构造负例和接近成功的样本，训练机器人奖励模型 | 下一步优先补“放在桌面、挂在篮沿、掉落、空抓”等可区分终态；不把当前所有放手状态作为成功 |
| [OpenGVL，2025 预印本](https://arxiv.org/abs/2509.17321) | 更广泛的视觉任务进度基准 | 候选外部基准。本轮没有在它上面训练或报告成绩 |
| [VIP，ICLR 2023](https://sites.google.com/view/vip-rl) | 目标条件视觉价值表示 | 目标图像可补充当前 DINO2 表示，但必须避免从测试录像挑目标图造成泄漏；本轮未训练 |
| [UVD，ICRA 2024](https://zcczhang.github.io/UVD/) | 用预训练视觉表示把长任务分解成子目标 | 支持阶段分解方向；本轮使用用户明确给出的任务定义，未将自动分解当成准确标签 |
| [V-JEPA 2，2025 预印本](https://arxiv.org/abs/2506.09985)；[Meta 原始介绍](https://ai.meta.com/research/publications/v-jepa-2-self-supervised-video-models-enable-understanding-prediction-and-planning/) | 预测潜在视觉状态，扩展到动作条件预测与规划 | 可为停滞、不可预测变化提供额外信号；完整大模型训练不适合本机 CPU 和现有样本规模，本轮未部署 |

没有从已核对的原始来源确认会议状态的工作，表中只标为预印本。CoRL、ICLR、ICCV、RSS、ICRA 都是会议。代码仓库继续用于核对作者实现、训练约定与许可证；评价方法是否先进，应看实验设计和结果。

SARM 的原始模型使用冻结 CLIP、视觉和关节状态、两类预测头以及更大的 Transformer；其附录还报告了腕部视角未在原任务上提供明显收益。这正是本轮保留单视角/双视角消融的原因，不能把论文的结论直接搬到 G1。我们改用本地合法可用的冻结 DINOv2，并比较小型 MLP 和两层 Transformer。训练目标采用阶段交叉熵及阶段内进度 MSE。阶段概率进入进度头，阶段先验只从训练录像估计。[SARM 正式论文](https://openreview.net/pdf/a003594857c5bc6d40ac553e082c79c1dcd1f921.pdf)

原始 ReWiND 还包括语言条件、多任务数据和策略强化学习；本轮只实现其视频倒放启发的增强。实验中该增强未超过无倒放时序候选，因此没有把“用到了更多论文”作为选型理由。[ReWiND 作者页面](https://rewind-reward.github.io/)

本轮结果、适用范围、代码入口及尚未解决的失败样例见 [模型升级报告](模型升级报告.md)。
