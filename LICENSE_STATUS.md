# License status — source preview

This is a source preview for download and inspection. No repository-wide open-source license has been applied.

The owner confirmed on 2026-09-17 that the origin or redistribution authorization of the initially supplied `mcap_viz` viewer still needs verification. Its license was not included in the supplied archive. The [file inventory](docs/licensing/base-viewer-files.json) lists 16 inherited or modified files, including the MCAP reader/server, URDF parser and parts of the browser viewer.

Completing the license review requires the actual copyright holder's redistribution/license terms for these files, or a verified replacement implementation. Their status remains unverified in this source preview.

Apache-2.0 is the proposed project license, stored as [a proposal](docs/licensing/PROPOSED_APACHE_2.0.txt). It has **not** been applied to the unresolved base files. Third-party components keep their own existing licenses and attribution; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The repository target is [Lee-hz/RoboCurate](https://github.com/Lee-hz/RoboCurate). Download availability and the unresolved license review are recorded separately in [RELEASE_STATUS.json](RELEASE_STATUS.json). Publishing the preview does not apply the proposed license to the unverified files.
